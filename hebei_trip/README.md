# 河北省14天自驾游地图可视化

这个项目使用Python创建了一个交互式地图，展示河北省14天自驾游的行程规划。

## 功能特点

- 显示所有途经城市和景点的位置
- 使用不同颜色标记区分起点/终点、途经城市和景点
- 显示完整的行程路线
- 包含详细的每日行程安排
- 交互式地图，可以点击查看具体位置信息

## 使用方法

1. 安装依赖：
```bash
pip install -r requirements.txt
```

2. 运行程序：
```bash
python hebei_trip_map.py
```

3. 在浏览器中打开生成的 `hebei_trip_map.html` 文件查看地图

## 地图说明

- 红色圆点：起点/终点（北京）
- 蓝色圆点：途经城市
- 绿色图标：景点位置
- 红色线条：行程路线
- 右侧面板：每日行程安排
- 左下角：图例说明

## 行程概览

- 总天数：14天
- 起点/终点：北京
- 途经城市：承德、秦皇岛、唐山、廊坊、保定、石家庄、邯郸、张家口
- 总行程：约2110公里
- 日均行驶：不超过250公里
